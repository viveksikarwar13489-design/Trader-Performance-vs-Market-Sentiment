# Trader-Performance-vs-Market-Sentiment
Analyze how market sentiment (Fear/Greed) relates to trader behavior and performance on Hyper liquid. Your goal is to uncover patterns that could inform smarter trading strategies.
Trader Performance vs Market Sentiment Analysis

## Project Overview
This project analyzes how market sentiment (Fear vs Greed) impacts trader profitability, behavior, and risk-taking patterns.

The analysis includes:
- Exploratory Data Analysis
- Sentiment-based performance comparison
- Trader segmentation using clustering
- Predictive modeling using Random Forest
- Interactive dashboard using Streamlit

---

## Objectives

1. Compare trader performance during Fear vs Greed markets
2. Analyze changes in trader behavior
3. Segment traders into behavioral archetypes
4. Predict next-day profitability
5. Recommend actionable strategies

---

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Plotly
- Scikit-learn

---

## Key Findings

- Greed days showed higher average profitability and better win rates.
- Fear days had larger drawdowns and lower performance.
- High leverage traders were more volatile.
- Disciplined traders delivered more stable returns.

---

## Strategy Recommendations

1. Reduce leverage during Fear sentiment periods.
2. Increase trade activity only for top-performing traders during Greed periods.
